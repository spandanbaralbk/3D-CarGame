# Car driving game  made by using javascript(vanilla)

 A simple yet engaging car game made by using javascript,html,css- no frameworks or libraries required. it includes real-time animation , collision detect , and responsive controls.

 # FEATURES
  1) Smooth car controls
  2) responsive ui
  3) custom graphics


# how to play 
1) clone the repo
2) open the game:-
    Open index.html in your browser

3) Play the game


https://spandanbaralbk.github.io/3D-CarGame/
